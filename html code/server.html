💬 Path 2: Missing Information

📅 Path 3: List Meetings

🗑️ Path 4: Cancel Meeting

START → CLASSIFIER → ROUTE → TOOLS (list) → CANCEL → OUTPUT → END

✨ Key Features

  • Conflict Detection: Every meeting checks for overlaps with existing events
  • Google Calendar Sync: Two-way sync with duplicate prevention
  • Chat Memory: Remembers context and preferences across conversations
  • Voice Support: Optional voice input/output via speech recognition
  • Smart Retry: Loops up to 5 times for complex operations
  • Multi-Source: Combines local storage and Google Calendar seamlessly

🔍 Node Responsibilities

  • CLASSIFIER: Uses GPT-4o-mini to understand intent and extract meeting parameters
  • CLARIFY: Interactive dialogue to gather missing information with voice/text
  • ROUTE: Maps classified intent to appropriate tool actions
  • TOOLS: Main executor - finds slots, creates meetings, lists events, handles operations
  • CANCEL: Specialized handler for meeting deletions with sync
  • OUTPUT: Formats responses, speaks output, saves to memory, adds warnings

🧠 State Management

  • State flows through all nodes carrying user intent, meeting details, and context
  • Contains 20+ fields including: intent, participants, slots, conflicts, messages
  • Loop counter prevents infinite loops (max 5 iterations)
  • Conditional edges use state to determine next node dynamically
  • Memory system persists across sessions for contextual awareness
